# Demo script

The full [`demo.lua` source](https://github.com/arsyny1x/Astra-Ui-Library/blob/main/demo.lua) is an interactive Astra UI dashboard demonstrating tabs, controls, themes, localization, and optional settings persistence.

To run it, use a compatible executor or runtime that provides `game:HttpGet` and `loadstring`. Its optional settings persistence also uses executor-provided `readfile` and `writefile` APIs. PNG images use the library's built-in decoder; no separate decoder setup is needed.

This page is also available at the legacy Docsify URL `#/demo.lua`.
