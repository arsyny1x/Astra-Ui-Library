# Complete example

This example shows the full library composition pattern loaded via `loadstring`. It requires an executor or runtime that provides `game:HttpGet` and `loadstring`; the current remote icon bootstrap is not supported by a standard Roblox client `LocalScript`. See [Quick start](quick-start.md).

The UI library only builds the interface. Connect callbacks to game logic you own, and keep server-authoritative game actions validated on the server.
