# การแก้ไขปัญหา

## รูปภาพไม่แสดง

1. ตรวจดู Roblox Output ว่ามีคำเตือน `[AstraUI] Unable to load ... PNG` หรือไม่
2. ตรวจสอบว่ากำหนดตัวถอดรหัสที่เข้ากันได้ผ่าน `PngDecoder` หรือมี ModuleScript ชื่อ `png` หรือ `luau-png` อยู่ใกล้เคียง
3. ตรวจสอบว่าตัวถอดรหัสเปิดเผย `supportsYieldIfNeeded = true` และรองรับตัวเลือก `yieldIfNeeded`
4. ตรวจสอบ runtime เป้าหมายว่ารองรับ `EditableImage` และได้รับสิทธิ์ที่จำเป็น
5. ตรวจสอบว่า URL ตอบกลับเป็นข้อมูล PNG หรือ JPEG baseline/progressive ที่รองรับ ระบบตรวจชนิดไฟล์จาก signature และปฏิเสธรูปแบบอื่นหรือรูปที่เกินขนาดและมิติที่กำหนด

## ไลบรารีทำงานผิดพลาดขณะโหลดไอคอน

ตัวโหลดไอคอนปัจจุบันดึงไลบรารีด้วย `game:HttpGet` และรันด้วย `loadstring` ซึ่งใช้กับ `LocalScript` ใน Roblox client มาตรฐานไม่ได้ หากใช้ใน experience ที่คุณเป็นเจ้าของ ให้ปรับ `main.lua` เพื่อใช้โมดูล/asset ไอคอนที่รวมไว้และตรวจสอบแล้ว อย่าแก้ปัญหาด้วยการรัน executor หรือรอฟังคำสั่งให้รันโค้ดที่ไม่รู้แหล่งที่มา

## การตั้งค่าไม่ถูกบันทึก

บันทึกสถานะได้ด้วย `GetState()` และ `SetState()` ไลบรารียังมี `SaveStateToFile()` และ `LoadStateFromFile()` เพื่อช่วยบันทึก JSON แต่ต้องใช้ file API ของ host เช่น `readfile`, `writefile`, `isfile`, `isfolder` และ `makefolder` ซึ่ง Roblox ไม่มีให้เป็น API มาตรฐาน หรือใช้ callback/storage ที่ host จัดเตรียม

## การเลือกผู้เล่นหายไป

`PlayerDropdown` แสดงเฉพาะผู้เล่นที่อยู่ในเซิร์ฟเวอร์ปัจจุบัน เมื่อผู้เล่นออก ระบบจะนำผู้เล่นคนนั้นออกจากตัวเลือก และตั้งใจไม่บันทึกการเลือกนี้ไว้
